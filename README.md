# RAFT Database Website
A website for Richmond Area Family Therapy - IS 302.
1. I used OpenAI Codex to build this website.
2. My first prompt was the exact prompt provided in the assignment instructions.
3. Codex didn't make any mistakes in the website creation, but it did fail to make the output available at first. I had to iterate a few times and ask it to help me access the files.
4. I made a change in the Client Lookup page. Originally, all of a client's appointments, past and future, were shown together on a client's page. I changed it so that upcoming appointments are shown first, with past appointments displayed below in a separate tab. This would help RAFT employees to have more visibility into upcoming appointments.
